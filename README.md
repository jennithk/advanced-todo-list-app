Advanced To-Do List App

A fully interactive client-side To-Do List application built using HTML, CSS, and JavaScript.

Features

- Add tasks
- Edit tasks
- Delete tasks
- Mark tasks as completed
- Filter tasks
  - All
  - Active
  - Completed
- Search functionality
- Dark mode toggle
- Clear completed tasks
- Task counter
- Local storage persistence

Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- LocalStorage API

Project Structure

advanced-todo-list-app/
│
├── index.html
├── style.css
└── app.js

How to Run

1. Download or clone the repository
2. Open the project folder
3. Run `index.html` in the browser
